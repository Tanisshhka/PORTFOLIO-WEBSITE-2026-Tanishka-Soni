# Tanishka Soni — Portfolio

A premium, bright-themed personal portfolio website for a Full Stack Developer.

## Features
- Modern responsive design
- Glassmorphism UI with vibrant gradients
- Animated particle background
- Typing effect hero section
- 13+ project showcase with live demo links
- 11 certifications gallery
- Contact form with Nodemailer (auto-reply included)
- Smooth scroll animations

## Tech Stack
- HTML5, CSS3, JavaScript
- Node.js + Express (contact form)
- Nodemailer (email service)
- Vercel (deployment)

## Deploy on Vercel
1. Push code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Login with GitHub
4. Import this repository
5. Deploy — no environment variables needed
